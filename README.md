# Compilador MiniPython

Proyecto académico enfocado en el desarrollo de un compilador/intérprete para un subconjunto simplificado del lenguaje Python, implementando análisis léxico, sintáctico y procesamiento de instrucciones.

---

# Descripción

Compilador MiniPython es un proyecto orientado al aprendizaje de conceptos fundamentales de:

- Compiladores
- Intérpretes
- Lenguajes formales
- Parsing
- Análisis de código
- Ejecución de instrucciones

El sistema busca interpretar una versión simplificada de Python, permitiendo procesar expresiones, variables, estructuras básicas y validaciones sintácticas.

---

# Objetivos del proyecto

- Simular el funcionamiento de un compilador/interprete.
- Comprender el flujo de análisis léxico y sintáctico.
- Procesar instrucciones similares a Python.
- Aplicar estructuras de datos y teoría de compiladores.
- Interpretar código fuente simplificado.

---

# Características principales

## Análisis léxico

- Tokenización de instrucciones.
- Identificación de palabras reservadas.
- Reconocimiento de operadores.
- Manejo de identificadores y variables.

## Análisis sintáctico

- Validación de estructura del código.
- Procesamiento de expresiones.
- Verificación básica de sintaxis.
- Construcción lógica del flujo de instrucciones.

## Interpretación

- Asignación de variables.
- Operaciones matemáticas.
- Evaluación de expresiones.
- Ejecución secuencial.

## Manejo de errores

- Errores léxicos.
- Errores sintácticos.
- Validaciones básicas del código fuente.
